# CampusIQ – Resume Project Descriptions & Bullet Points

Use these bullet points on your resume, tailored to the specific role you are applying for during placement drives.

---

## Option 1: For Software Development Engineer (SDE) / Full-Stack Roles

**CampusIQ – College Academic Intelligence & Student Success Platform**  
*Tech Stack: Python, FastAPI, React.js, SQLAlchemy, SQLite/PostgreSQL, Scikit-Learn, Tailwind CSS, JWT*

- Architected a full-stack academic intelligence platform replacing fragmented university records with role-based dashboards for 1,200+ students, faculty, and administrators.
- Developed 15+ secure RESTful endpoints in **FastAPI** utilizing Pydantic v2 validation, SQLAlchemy 2.0 ORM, and OAuth2 JWT authentication with Role-Based Access Control (RBAC).
- Integrated an Explainable **Scikit-Learn Random Forest Classifier** (94.7% accuracy, 0.949 Macro F1) to predict student academic failure risk, identifying driving risk factors via Gini feature importances.
- Engineered an interactive **What-If CGPA Simulator** and goal-seeking solver calculating credit-weighted SGPA/CGPA trajectories and minimum attendance thresholds to prevent exam detentions.
- Built a responsive **React 18** frontend featuring dynamic Recharts data visualizations, placement readiness radar charts, and an AI advisory drawer.

## Option 2: For Machine Learning / Data Science / AI Engineer Roles

**CampusIQ – Academic Intelligence & Predictive Analytics Platform**  
*Tech Stack: Python, Scikit-Learn, Pandas, NumPy, FastAPI, Google Gemini API, RAG, Joblib*

- Formulated an academic early-intervention ML pipeline evaluating multidimensional student metrics (attendance, internal marks, continuous assignments, past CGPA, and backlogs).
- Evaluated and benchmarked **Logistic Regression (84.7%)**, **Decision Trees (92.3%)**, and **Random Forest (94.7%)**; selected Random Forest to prevent overfitting and capture non-linear student interaction signals.
- Developed an Explainable AI diagnostic engine leveraging Gini feature importances (Attendance: 33.3%, Backlogs: 24.5%, CGPA: 19.9%) to output transparent, human-readable remediation plans.
- Implemented **CampusAI**, an academic advisor using Retrieval-Augmented Generation (RAG) concepts with Google Gemini LLM API and deterministic context injection of student transcripts.
- Created a multi-criteria Placement Readiness scorecard combining technical DSA benchmarks, programming velocity, aptitude tests, and verified portfolio projects.
